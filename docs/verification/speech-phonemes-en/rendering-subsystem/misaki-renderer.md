### MisakiRenderer Verification

#### Verification Approach

`MisakiRenderer` is verified by unit tests in `test/DemaConsulting.Speech.Phonemes.En.Tests/RenderingSubsystemTests.cs`
(the `MisakiRenderer_*` tests) that run the real phonemizer and the renderer. The main evidence is the golden corpus
`TestData/kokoro-misaki-golden.tsv`: the rendering of every one of the 150 reviewed sentences with the token ids of
Kokoro's vocabulary, regenerated by `regenerate-goldens --renderers` and reviewed. The exhaustive symbol coverage is the
subsystem test.

#### Test Environment

- **Framework**: xUnit v3 running under the .NET SDK
- **Execution**: `dotnet test` invoked by `build.ps1` and the CI pipeline
- **Files**: the golden file and Kokoro's own tokenizer file (linked from the Kokoro package), copied next to the test
  assembly
- **Isolation**: no network, no model

#### Acceptance Criteria

Every sentence of the golden corpus (at least 150) renders to exactly its reviewed string, non-empty, with no symbol
outside Kokoro's vocabulary, and its token ids equal the golden ids; a null text, a part limit of 15 and the undefined
profile 99 are rejected with argument errors.

#### Test Scenarios

##### Golden corpus

**Test**: `MisakiRenderer_Render_Sentences_RenderTheReviewedPhonemeStrings`

##### Invalid arguments

**Test**: `MisakiRenderer_Render_InvalidArguments_AreRejected`

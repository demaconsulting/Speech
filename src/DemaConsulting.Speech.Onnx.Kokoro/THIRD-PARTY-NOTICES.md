## misaki

- **Source**: <https://github.com/hexgrad/misaki>
- **Author**: hexgrad
- **License**: Apache License, Version 2.0, reproduced in full below.
- **NOTICE file**: the upstream repository has no `NOTICE` file (checked on 2026-11-15), so there
  are no further attribution notices to reproduce.
- **Used in**: the phoneme strings of `kokoro-en-lexicon.tsv.gz`. They were generated offline by
  running `misaki.en.G2P` over the CMUdict-derived words. The English pronunciation lookup of
  `misaki.en.G2P` reads misaki's own gold and silver dictionaries (`misaki/data/us_gold.json` and
  `misaki/data/us_silver.json`), so the lexicon can contain pronunciations taken from those files.
- **Changes**: misaki's output was precomputed once into the lexicon, together with the filtering
  described above. No misaki source code is shipped in this package.

### Provenance of misaki's Data Files

Upstream does not document the provenance of the `misaki/data/*.json` dictionaries in the
repository itself: its README and source code are silent, and it has no data license or `NOTICE`
file. The only statement by the maintainer that was found is a comment on issue 51 of the misaki
repository (14 February 2025), which says:

- the `_gold.json` dictionaries were obtained by seeding "some local datasets of IPA labels" and
  then mapping and filtering them programmatically with heuristics; the datasets are not named;
- the `_silver.json` dictionaries were obtained by running `espeak-ng==1.52` against the
  `words_alpha.txt` list of the `dwyl/english-words` project, transforming the phonemes, and
  keeping only entries consistent with the gold dictionaries.

Open issues 107 and 113 of the misaki repository ask for the sources and the license of these data
files; no maintainer reply had been published on them on 2026-11-15. Beyond the Apache-2.0 license
of the misaki repository, this package therefore claims nothing about the license of those data
files, and no further notice could be added from verified sources.

## Data of Unknown Origin

The lexicon `kokoro-en-lexicon.tsv.gz` has an optional third column, a word-frequency score used to
rank spelling corrections. The tool and data set that produced this score are not documented in
this repository, so this file makes no statement about their license.
